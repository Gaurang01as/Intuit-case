Build on IES data

Every automated, assisted, and human-reviewed action in IES is available as an event your app can subscribe to — so a bakery POS system, a payroll add-on, or a lending tool can react the moment the books close.

Example: subscribe to close events

GET /v1/companies/sundial-bakehouse/events
Authorization: Bearer <token>

{
  "event": "books.closed",
  "period": "2026-08",
  "mode": "automated",
  "exceptions": 0
}
